# Веб-сервис для управления движением денежных средств (ДДС)

Бэкенд-приложение на Django для учета, управления и анализа поступлений и списаний денежных средств

**Язык программирования:** Python 3.12+
**Фреймворк:** Django 6+ (Django ORM)
**База данных:** SQLite
**Интерфейс:** Стандартная панель администратора Django
